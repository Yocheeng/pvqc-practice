# PVQC 計算機－應用練習室

使用者提供的 645 筆計算機－應用詞彙已內建，保留序號、英文大小寫、完整中文翻譯與詞性。

六個題型：看中拼英、看英選中、聽英選中、聽英選英、看中選發音、看英選發音。可單關練習、六關連續練習及按關卡複習錯題。

新增「小考練習」：依原序號每 50 個一組（1–50、51–100…），供每兩週看中拼英小考前使用。可選 13 組，組內打亂順序但完整出題；最後 601–645 為 45 題。開始前能展開本組詞彙複習，作答後立即核對答案，結束顯示答對率、錯字、輸入答案，並可重練整組或只練本次錯字。錯字沿用第 1 關的瀏覽器錯題紀錄。小考接受同組內同中文、同字元數的英文答案；不接受其他組的替代答案。未提供有效且唯一序號的自訂題庫改按匯入順序分組，介面標為「第幾筆」。

## 使用

開啟 dist/index.html 即可使用，或在此資料夾啟動本機網站：

```powershell
python -m http.server 5178 --bind 127.0.0.1 --directory dist
```

題庫檔為 course-vocabulary.json / course-vocabulary.csv；網頁內建版本在 dist/course-data.js。網頁「我的題庫」可讀取 CSV、TSV、TXT、JSON 或貼上中英兩欄資料；修改只儲存在目前瀏覽器，並不修改網站內建題庫。

## 題庫處理

- 序號 1–645 完整連續；645 個大小寫區分的英文詞彙，605 種中文詞義。
- DOS（原序號 191，磁片作業系統）與 DoS（384，阻斷服務）保留為不同詞彙。
- 拼字題提供含空格的字元數。相同中文、相同長度且都在題庫內的英文答案皆可接受；判分忽略大小寫與頭尾空白，保留詞彙中的空格、連字號及斜線。
- 中文選擇題避免重複中文選項；發音選項在作答前只顯示序號與播放按鈕。
- 原翻譯存在疑似筆誤，例如 DDoS 的「分裂式阻斷服務」、terabyte 的「TG」、P2P 的「點對點對點式」。依使用者題庫原文保留，應由老師确认版本後再修改。

## 限制

本版為不限時練習，顯示練習用時與答對率；小考練習會逐題核對拼字。六種題型參考 https://system.jyic.net/PVQC/L-SOP.pdf ，該文件是舊版測評說明且主題為數位多媒體；未把其題數、時限、及格分數套成使用者課程的正式規則。實際小考規則依老師提供的版本確認。

語音使用瀏覽器 SpeechSynthesis；並非原版考試錄音。全大寫縮寫逐字母朗讀，其他詞彙依英語語音引擎朗讀。不同裝置聲音可能不同，播放受瀏覽器限制時需按播放按鈕重試。

錯題與自訂題庫存在目前來源的 localStorage；不同網域、裝置及瀏覽器不會同步，清除網站資料會刪除自訂紀錄。網站內建的 645 筆課程題庫仍會保留。

## 驗證

已核對 645 筆來源及四欄原文，並檢查 JavaScript 語法。隔離環境完成 1,483 項行為檢查，涵蓋六關連續練習、發音選項、小考分組出題、判分、錯字複習與重練。同一中文詞義不會被安排成看中選發音的干擾選項。實際瀏覽器畫面檢查涵蓋桌面與手機版。人工聽音品質與正式測驗規則尚未核實。
